# BuK-Trainer

Interaktiver Übungstrainer für Berechenbarkeit und Komplexität: DFA, Kellerautomaten und Turingmaschinen bauen (mit exakter Prüfung),
Potenzmengenkonstruktion, Minimierung, Pumping-Lemma-Spiel, CYK, Zuordnungsaufgaben, Mastertheorem/Landau, Beweis-Puzzles,
mündliche Prüfungsfragen mit Selbstcheck, Prüfungssimulation und ein täglicher Übungsmix mit Wiederholungen.

**Starten:** https://asamedia.github.io/buk-trainer/ – auf dem Handy über das Browsermenü zum Startbildschirm hinzufügen.
Der Fortschritt bleibt im Browser des jeweiligen Geräts; nach dem ersten Laden geht alles auch offline.

Die Seite wird außerhalb dieses Repos aus den Quellen gebaut (`build_trainer.py`); hier liegt nur das Ergebnis.
