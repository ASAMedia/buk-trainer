# BuK-Trainer

Interaktiver Übungstrainer zur Vorlesung Berechenbarkeit und Komplexität (FSU Jena): DFA, Kellerautomaten und Turingmaschinen
bauen (mit exakter Prüfung), Potenzmengenkonstruktion, Minimierung, Myhill-Nerode-Klassen, Pumping-Lemma-Spiel, CYK,
Reduktionen (Halteproblem, 3-SAT → CLIQUE → Vertex Cover, HK → TSP), Zuordnungsaufgaben, Mastertheorem/Landau, Beweis-Puzzles,
mündliche Prüfungsfragen mit Selbstcheck, Prüfungssimulation und ein täglicher Übungsmix mit Wiederholungen.

**Starten:** https://asamedia.github.io/buk-trainer/ – kein Konto nötig. Auf dem Handy über das Browsermenü „App installieren“
bzw. „Zum Startbildschirm hinzufügen“; nach dem ersten Laden geht alles auch offline.
Der Fortschritt bleibt im Browser des jeweiligen Geräts und lässt sich per Code auf ein anderes Gerät übertragen („Fortschritt“ oben rechts).

Inoffizielle Übungssammlung, ohne Gewähr. Fehler gefunden? Bitte als [Issue](https://github.com/ASAMedia/buk-trainer/issues) melden.

Die Seite wird außerhalb dieses Repos aus den Quellen gebaut (`build_trainer.py`); hier liegt nur das Ergebnis.
